# Job-Market RAG

An assistant that answers "what skills does this role want?" from real public job postings, with citations to the postings it used.

## Status
Setup stage. Nothing runs yet.

## Planned pipeline
Public job postings -> cleaning (Python, SQL) -> Postgres -> embeddings and vector search -> RAG assistant -> FastAPI -> Docker -> CI
